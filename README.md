# Pack Organizer

A Forge 1.8.9 mod that makes the Resource Packs screen easier to use with a lot of packs: a search box, resolution filters and labels, pack folders, item previews on hover and a color wheel that sorts packs by color. It pairs with [fastpacks](https://github.com/as9pa/fastpacks) but works alone.

![The Resource Packs screen with Pack Organizer](docs/images/screen.png)

See [docs/details.md](docs/details.md) for the full feature list and settings.
