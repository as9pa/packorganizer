# Pack Organizer

A Forge 1.8.9 mod that makes the Resource Packs screen easier to use with a lot of packs: a search box, resolution filters and labels, pack folders, favorites, item previews, a Previews list mode, a color wheel that sorts packs by color, and a 3D player preview that wears the hovered pack's armor and items with your own skin. It has the speed-ups from [fastpacks](https://github.com/as9pa/fastpacks) built in, so it is fast on its own, and it works alongside fastpacks too.
